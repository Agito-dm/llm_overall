# Day 4 – Classification and Routing

## Цель

Реализовать классификацию пользовательских запросов, определение intent и явную маршрутизацию генерации ответов.

## Реализация

Разработаны модули `categories.py`, `classifier.py`, `routing.py`, а также `routed_pipeline.py`.

Используются пять категорий запросов. Сначала Gemini возвращает `category` и `intent`, затем Python выбирает инструкцию генерации через `get_route()`. Итоговый ответ формируется отдельным обращением к модели.

Структура результата проверяется с помощью Pydantic. Сохранена совместимость с предыдущими этапами проекта.

## Результаты

- Автоматические тесты: 55 успешно.
- Проверки Ruff: без замечаний.
- Реальные тестовые тексты: 10.
- Первый прогон: 7/10 полных успешных обработок, включая два ограничения HTTP 429 и одну ошибку формата.
- Второй прогон: 8/10 полных успешных обработок; два ответа содержали дополнительные поля JSON.
- После выявления причин добавлена контролируемая обработка известных избыточных полей и четыре дополнительных тестовых случая.
- Повторный полный прогон после исправления не проводился.

Маршрутизация проверена для всех пяти категорий. Ответы технической поддержки, жалоб и запросов о покупке содержательно различаются.

## Вывод

Основные требования Дня 4 реализованы. Пайплайн определяет категорию и intent, выбирает инструкции генерации явно в Python, возвращает структурированный ответ и выполняет проверку его схемы.

В последующих этапах планируется улучшить устойчивость к ошибкам API и развить многошаговую обработку с self-check.
