## 1. Финальная архитектура

Реализован модульный Python-проект с тремя режимами работы:

- Basic pipeline — обработка текста, summary, key points и final answer.
- Routed pipeline — классификация запроса и маршрутизация генерации.
- Full pipeline — пятиэтапная обработка с проверкой результата.

Основной интерфейс запуска — `main.py`.

Полный pipeline содержит пять этапов:

1. Extract meaning.
2. Classify request.
3. Build structured fields.
4. Generate final answer.
5. Self-check result.

Этапы обмениваются промежуточными результатами. Генерация итогового ответа использует результаты анализа, классификации и routing logic.

## 7. Ограничения проекта

Проект является учебным single-pipeline mini-product, а не production-сервисом.

Его ограничения:

- Работа зависит от доступности внешней LLM.
- Возможны ограничения RPM, TPM и RPD.
- Fallback не гарантирует фактическую достоверность ответа.
- Self-check является дополнительной проверкой, а не независимой экспертной оценкой.
- Нет подключения к внешним системам поддержки, оплаты и продаж.

## 8. Итоговый вывод

Функциональность семи этапов интегрирована в единый модульный LLM workflow.

Система принимает пользовательский текст, извлекает структуру, определяет категорию и намерение, выбирает маршрут генерации, формирует итоговый JSON и проверяет результат.

Автоматические тесты и реальные демонстрационные сценарии подтверждают работоспособность основных компонентов.

Окончательное подтверждение воспроизводимости будет внесено после проверки опубликованного чистого клона.
